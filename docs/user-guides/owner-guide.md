# Owner Guide

Panduan penggunaan untuk Owner (Pemilik Outlet).

## 🎯 Overview

Sebagai Owner, Anda memiliki akses penuh untuk mengelola outlet Anda, termasuk:
- Mengelola staff
- Mengelola layanan dan harga
- Melihat laporan dan analitik
- Mengelola pesanan

## 📋 Menu Utama

### Dashboard
- Ringkasan order hari ini
- Omzet harian
- Statistik order per status
- Cucian tertunda

### Orders
- Daftar semua pesanan
- Buat pesanan baru
- Update status pesanan
- Cetak invoice

### Services
- Daftar layanan (Kiloan, Satuan, Paket)
- Tambah/edit layanan
- Kelola harga

### Users
- Daftar staff
- Tambah/edit staff
- Atur role staff

### Reports
- Laporan keuangan
- Laporan harian/mingguan/bulanan
- Export ke Excel/PDF

## 🚀 Quick Start

### 1. Login

1. Buka aplikasi
2. Masukkan email dan password
3. Klik "Sign In"

### 2. Buat Order Baru

1. Navigasi ke **Orders** → **New Order**
2. Isi data customer
3. Pilih layanan
4. Masukkan jumlah/berat
5. Klik "Create Order"
6. Sistem akan generate tracking code

### 3. Update Status Order

1. Buka order detail
2. Klik tombol status
3. Pilih status baru (WASHING → DRYING → IRONING → READY)
4. Status akan terupdate

### 4. Tambah Staff

1. Navigasi ke **Users** → **Add User**
2. Isi data staff
3. Pilih role "STAFF"
4. Set password
5. Klik "Create User"

## 📊 Reports

### Daily Report

1. Navigasi ke **Reports** → **Daily**
2. Pilih tanggal
3. Lihat ringkasan:
   - Total orders
   - Total revenue
   - Orders per status

### Export Report

1. Buka report yang diinginkan
2. Klik "Export"
3. Pilih format (Excel/PDF)
4. Download file

## 🔐 Security

- Jangan share password dengan staff
- Gunakan password yang kuat
- Logout setelah selesai
- Jangan akses dari device tidak aman

## ❓ FAQ

**Q: Bagaimana cara reset password staff?**
A: Buka Users → Edit User → Reset Password

**Q: Bagaimana cara ubah harga layanan?**
A: Buka Services → Edit Service → Update Price

**Q: Bagaimana cara cetak invoice?**
A: Buka Order Detail → Klik "Print Invoice"
