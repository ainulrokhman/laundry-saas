## 🎭 User Roles

### SUPERADMIN
- Full access to all outlets
- Manage subscriptions
- System administration

### OWNER
- Full access to own outlet
- Manage users (staff)
- View reports and analytics
- Manage services and pricing

### STAFF
- Limited access to own outlet
- Create and manage orders
- Update order status
- View orders

### CUSTOMER (Public)
- Track orders via tracking code
- View order status
- Upload payment proof
